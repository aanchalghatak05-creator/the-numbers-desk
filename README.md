# The Numbers Desk — website starter

This is a first independent-hosting starter based on the existing The Numbers Desk preview. It is a static website and does not yet include a CMS or a custom domain. The three story cards are clearly labelled as reporting plans, not published findings.

## Files
- `index.html` — responsive homepage.

## Next steps
1. Create a new public GitHub repository named `the-numbers-desk`.
2. Upload `index.html` and this README to the repository root.
3. Import the repository into Netlify and deploy it. Netlify will provide a temporary `*.netlify.app` address.
4. After the site is live, add a CMS and configure it to publish articles from the repository. CMS setup needs repository-specific configuration and authentication, so it should be done after the repository exists.
5. Add a domain later if you decide to buy one.

Before launch, replace the contact email if needed, verify all external links, and add a real contact method and privacy notice appropriate to the site's actual analytics and data collection.
